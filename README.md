Archive and single-repo upload of the various o2r mods for SoH I've thrown together.

Crenando - Ganondorf -> Crenando label and text replacement
GC Input Colors -> GameCube colors for SoH input monitor
Jabu Nikocado -> yea
Maxwell Triforce -> Replaces Triforce Hunt pickups with Maxwell the Cat
MM Anims -> Replaces the few subtly-different anims (eg bottling) with MM counterparts.
MM Deku Stick -> stick
MM_Flips -> Credit to Neirn. Individual replacements for the jump anim with an MM Flip of choice. Note: The soh_fd fork makes this obsolete, go use that fork instead for actual random flips.
MM_Music -> Optional MM music wherever you want for grottos, field, boss, miniboss, battle
Morshu -> Morshu from Ultimate Trial, with custom signs for his shops and custom dialogue.
1.0 Gerudo -> OOT 1.0 Gerudo un-censoring
SW97 Stuff -> dude funny beytah lmao
TML Autumn LostWoods -> Textures using The Missing Link's color palette for the forest areas, and also music from TML for grottos and the Lost Woods.
TML / Ultimate Trial Buttons -> Two button-replacement mods that change the HUD buttons to the two romhacks' buttons.
